# acompanhamento-de-estudos

Repo **privado** de estado dos estudos. Aqui fica o que foi feito, o que falta e o próximo passo de cada tema, para que qualquer sessão nova continue de onde a anterior parou.

- `INDICE.md`: um tema por linha.
- `temas/<tema>/ESTADO.md`: estado do pipeline do plano de estudos (gerente-estudadora).
- `temas/<tema>/PROGRESSO.md`: estado do estudo (tutora).
- `temas/<tema>/PLANO-FINAL.md`: o plano que a tutora segue.
- `temas/<tema>/material/`: PDFs e transcrições. **Fora do git.**
- `MODO-TUTOR.md`: o método da tutora.
- `temas/_modelo/`: copie para começar um tema.

Como uma sessão se localiza: `CLAUDE.md`.
