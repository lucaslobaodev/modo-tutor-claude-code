# modo-tutor-claude-code

Modo de atuação do Claude Code como **tutor** num projeto de aprendizado: o agente ensina, o aluno escreve o código, o agente revisa, o aluno roda.

O modo em si está em [MODO-TUTOR.md](MODO-TUTOR.md). Ele é versionado aqui e ajustado conforme a prática mostra o que funciona.
